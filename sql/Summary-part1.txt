# SQL COMPLETE SUMMARY NOTES

These are **complete SQL revision notes from basics to normalization**, arranged in the order you should study them. Everything is directly copyable.

---

# 1. SQL

**SQL = Structured Query Language**

SQL is used to communicate with and manage data in a **relational database**.

SQL can be used to:

* Create databases and tables
* Insert data
* Retrieve data
* Update data
* Delete data
* Filter and sort data
* Combine tables
* Apply constraints
* Create views and triggers
* Manage transactions

---

# 2. DATABASE

A **database** is an organized collection of data.

### Create database

```sql
CREATE DATABASE company;
```

### Select database

```sql
USE company;
```

### Show databases

```sql
SHOW DATABASES;
```

### Delete database

```sql
DROP DATABASE company;
```

---

# 3. TABLE

A **table** stores data in rows and columns.

### Create table

```sql
CREATE TABLE employees (
    id INT,
    name VARCHAR(50),
    age INT,
    salary DECIMAL(10,2)
);
```

### View table structure

```sql
DESC employees;
```

### Display all data

```sql
SELECT * FROM employees;
```

---


# 5. DDL

**DDL = Data Definition Language**

DDL is used to define and modify the **structure** of database objects.

Main commands:

```text
CREATE
ALTER
DROP
TRUNCATE
RENAME
```

---

## CREATE

Creates a database/table/object.

```sql
CREATE TABLE employees (
    id INT,
    name VARCHAR(50)
);
```

---

## ALTER

Changes the structure of an existing table.

### Add column

```sql
ALTER TABLE employees
ADD COLUMN age INT;
```

### Add multiple columns

```sql
ALTER TABLE employees
ADD COLUMN city VARCHAR(50),
ADD COLUMN salary DECIMAL(10,2);
```

### Modify column

```sql
ALTER TABLE employees
MODIFY COLUMN name VARCHAR(100);
```

### Rename column

```sql
ALTER TABLE employees
RENAME COLUMN name TO employee_name;
```

### Drop column

```sql
ALTER TABLE employees
DROP COLUMN age;
```

---

## DROP

Deletes the table completely.

```sql
DROP TABLE employees;
```

The table structure and data are removed.

---

## TRUNCATE

Removes all rows but keeps the table structure.

```sql
TRUNCATE TABLE employees;
```

---

## RENAME

Renames a table.

```sql
RENAME TABLE employees TO emp;
```

---

# 6. DML

**DML = Data Manipulation Language**

Used to manipulate the data inside tables.

Main commands:

```text
INSERT
UPDATE
DELETE
```

---

## INSERT

### Insert one row

```sql
INSERT INTO employees
VALUES (1, 'Rahul', 25, 50000);
```

### Insert specific columns

```sql
INSERT INTO employees
(id, name, salary)
VALUES
(2, 'Anjali', 60000);
```

### Insert multiple rows

```sql
INSERT INTO employees
VALUES
(3, 'Priya', 70000),
(4, 'Kiran', 55000);
```

---

## UPDATE

Used to modify existing data.

```sql
UPDATE employees
SET salary = 65000
WHERE id = 2;
```

⚠️ Always be careful with `UPDATE` without `WHERE`.

```sql
UPDATE employees
SET salary = 65000;
```

This updates **every row**.

---

## DELETE

Deletes rows.

```sql
DELETE FROM employees
WHERE id = 2;
```

Without `WHERE`:

```sql
DELETE FROM employees;
```

all rows are deleted.

---

# 7. DQL

**DQL = Data Query Language**

Main command:

```text
SELECT
```

### Select everything

```sql
SELECT * FROM employees;
```

### Select specific columns

```sql
SELECT name, salary
FROM employees;
```

---

# 8. WHERE

`WHERE` is used to filter rows.

```sql
SELECT *
FROM employees
WHERE salary > 50000;
```

### Operators

```text
=       Equal
<>      Not equal
!=      Not equal
>       Greater than
<       Less than
>=      Greater than or equal
<=      Less than or equal
```

Example:

```sql
SELECT *
FROM employees
WHERE age >= 25;
```

---

# 9. LOGICAL OPERATORS

## AND

Both conditions must be true.

```sql
SELECT *
FROM employees
WHERE salary > 50000
AND age > 25;
```

## OR

At least one condition must be true.

```sql
SELECT *
FROM employees
WHERE dept = 'IT'
OR city = 'Chennai';
```

## NOT

Negates a condition.

```sql
SELECT *
FROM employees
WHERE NOT dept = 'IT';
```

### Important

When combining `AND` and `OR`, use parentheses.

```sql
SELECT *
FROM employees
WHERE salary > 50000
AND (dept = 'IT' OR city = 'Chennai');
```

---

# 10. BETWEEN

Checks whether a value is within a range.

```sql
SELECT *
FROM employees
WHERE salary BETWEEN 50000 AND 80000;
```

### NOT BETWEEN

```sql
SELECT *
FROM employees
WHERE salary NOT BETWEEN 50000 AND 80000;
```

---

# 11. IN

Checks whether a value matches any value in a list.

```sql
SELECT *
FROM employees
WHERE city IN ('Bangalore', 'Mumbai', 'Chennai');
```

### NOT IN

```sql
SELECT *
FROM employees
WHERE city NOT IN ('Bangalore', 'Mumbai');
```

---

# 12. LIKE

Used for pattern matching.

### Starts with A

```sql
SELECT *
FROM employees
WHERE name LIKE 'A%';
```

### Ends with A

```sql
SELECT *
FROM employees
WHERE name LIKE '%a';
```

### Contains A

```sql
SELECT *
FROM employees
WHERE name LIKE '%a%';
```

### One character

`_` represents one character.

```sql
SELECT *
FROM employees
WHERE name LIKE '_a%';
```

### Wildcards

```text
% → Zero or more characters
_ → Exactly one character
```

---

# 13. NULL

`NULL` means **missing/unknown value**.

Don't use:

```sql
WHERE manager_id = NULL;
```

Use:

```sql
WHERE manager_id IS NULL;
```

### Not NULL

```sql
WHERE manager_id IS NOT NULL;
```

---

# 14. DISTINCT

Removes duplicate values from the result.

```sql
SELECT DISTINCT city
FROM employees;
```

Multiple columns:

```sql
SELECT DISTINCT dept, city
FROM employees;
```

Here duplicate **combinations** are removed.

---

# 15. ORDER BY

Used to sort results.

### Ascending

```sql
SELECT *
FROM employees
ORDER BY salary ASC;
```

### Descending

```sql
SELECT *
FROM employees
ORDER BY salary DESC;
```

`ASC` is the default.

---

# 16. LIMIT

Restricts the number of rows returned.

```sql
SELECT *
FROM employees
LIMIT 5;
```

Returns first 5 rows after applying the query's filtering/sorting.

---

# 17. OFFSET

Skips rows.

```sql
SELECT *
FROM employees
LIMIT 5 OFFSET 10;
```

Meaning:

```text
Skip 10 rows
↓
Return next 5 rows
```

Useful for pagination.

---

# 18. AGGREGATE FUNCTIONS

Aggregate functions perform calculations on multiple rows.

Main functions:

```text

SUM()
AVG()
```

## COUNT

Counts rows.

```sql
SELECT COUNT(*)
FROM employees;
```

```sql
SELECT dept, COUNT(*)
```

---

## AVG


---

## MIN

```sql
SELECT MIN(salary)
FROM employees;
```

---

## MAX

```sql
SELECT MAX(salary)
FROM employees;
```

# 19. GROUP BY

`GROUP BY` groups rows having the same value.

Example:

```sql
SELECT dept, AVG(salary)
FROM employees
GROUP BY dept;
```

Result conceptually:

```text
IT       → average salary
HR       → average salary
Finance  → average salary
```

---

# 20. HAVING

`HAVING` filters **groups**.

Example:

```sql
SELECT dept, AVG(salary) AS average_salary
FROM employees
GROUP BY dept
HAVING AVG(salary) > 70000;
```

### WHERE vs HAVING

```text
WHERE  → Filters rows
HAVING → Filters groups
```

Example:

```sql
SELECT dept, AVG(salary)
FROM employees
WHERE salary > 40000
GROUP BY dept
HAVING AVG(salary) > 70000;
```
