STORED PROCEDURES IN MY SQL:
A Stored procedure is a group of SQL statements stored in the database and executed whenever 
we call the procedure.It allows us to write a set of SQL operations once and reuse many times.

Features
Reusable
parameters
multiple statements
stored in database 

syntax:
DELIMITER //
CREATE PROCEDUERE procedure_name()
BEGIN
	SQL statement-1;
	SQL statement-2;
END//
DELIMITER;

*We use delimiter to change the termination , by default sql understands ; as the end of the query but in procedures we have multiple queries so we have to change the delimiter to tell sql that the procedure is not yet completed.

Q: find emp names based on given starting name 
delimiter $$
create procedure emp_name_start_with(IN start varchar(50))
begin
	select * from emp where employee_name like 'start%';
end $$


mysql> delimiter ;
mysql> call emp_name_start_with('a');
Empty set (0.01 sec)

delimiter $$

create procedure emps_name_start_with(IN start varchar(50))
begin
select * from emp where employee_name like concat(start,'%');
end $$

delimiter ;
call emps_name_start_with('a')
