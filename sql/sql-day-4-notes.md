# **DML COMMANDS**

## **Data Manipulation Language:It is used to manipulate the data in the existing table.**

### **->such as creating new data , updating , deleting data in the table.**

##### **DML COMMANDS**

##### **INSERT -> Used to add a new row in a the existing table.** 

##### **UPDATE -> Update the existing data in the table**

##### **DELETE -> deleting the row in the table**
