INDEXES:
An index helps find MySQL find rows faster when a column is searched often.
an index is a separate search structure maintained by MySQL to help find rows faster .It is useful
mainly when a table has many rows and we frequently search or filter using a column 

example: SELECT * 
FROM emp WHERE employee_name = "Rahul";

Why do we use indexes?
*To make searching rows faster 
*To improve a 

Syntax:
CREATE INDEX INDEX_NAME ;
ON emp(employee_name);
