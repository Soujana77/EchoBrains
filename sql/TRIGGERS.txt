TRIGGERS:
A Trigger is a special type of stored program that automatically executes when a specific event occurs on a table.
Trigger = Automatically executes a SQL statement when an INSERT, UPDATE, or DELETE happens.

1. Why do we use Triggers?

*Triggers are commonly used for:

->Automatically recording changes
->Maintaining audit/history tables
->Validating data
->Automatically updating related information
->Keeping logs of INSERT, UPDATE, or DELETE
->Enforcing business rules

 CREATE TRIGGER insert_before_trigger
    -> BEFORE INSERT ON emp
    -> FOR EACH ROW
    -> BEGIN
    -> IF NEW.salary < 0 THEN SET NEW.salary = 10 ;
    -> END IF;
    -> END $

CREATE TRIGGER ater_insert
    -> AFTER INSERT
    -> ON emp
    -> FOR EACH ROW
    -> BEGIN
    -> insert into emp_history values(1,NEW.employee_name,"insert",new.employee_id);
    -> END *

1.Create a trigger on emp table on delete history keep the deleted data in emp_history table
delimiter *
mysql> CREATE TRIGGER before_delete
    -> BEFORE DELETE
    -> on emp
    -> for each row
    -> BEGIN
    -> insert into emp_history values(2,OLD.employee_name,'insert',old.employee_id);
    -> END *
 delete from emp where employee_id = 1;
