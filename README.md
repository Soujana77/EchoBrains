# 🐍 Python Programming Basics

A beginner-friendly collection of Python programs, theory notes, and practice exercises covering the fundamental concepts of Python programming. This repository is designed to help students prepare for practical exams, interviews, and strengthen their programming skills.

---

### 1. Python Basics

* Introduction to Python
* Features of Python
* Variables
* Rules for Naming Variables
* Data Types
* Input and Output
* Type Casting
* Escape Sequences

### 2. Operators

* Arithmetic Operators
* Assignment Operators
* Comparison Operators
* Logical Operators
* Bitwise Operators
* Membership Operators
* Identity Operators

### 3. Conditional Statements

* `if`
* `if-else`
* `if-elif-else`
* Nested `if`

### 4. Loops

* `for` Loop
* `while` Loop
* Nested Loops
* Pattern Printing

### 5. Jumping Statements

* `break`
* `continue`
* `pass`

### 6. Lists

* List Creation
* Indexing
* Slicing
* List Operations
* Built-in Functions
* Practice Programs

### 7. Strings

* String Operations
* Indexing
* Slicing
* Built-in Functions
* String Manipulation Programs

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Soujana77/EchoBrains.git
```

2. Navigate to the project folder:

```bash
cd EchoBrains
```

3. Run any Python program:

```bash
python filename.py
```
