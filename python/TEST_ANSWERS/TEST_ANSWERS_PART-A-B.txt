2. Difference between == and is
==

Checks whether two values are equal.

is

Checks whether two variables refer to the same object in memory.

a = [10, 20]
b = [10, 20]

print(a == b)
print(a is b)

Output:

True
False

Because the values are the same, but they are different list objects.

4. Difference between return and yield
return
Returns a value from a function.
Terminates the function.
yield
Produces a value one at a time.
Makes the function a generator.
Preserves the function's state between calls.
def test():
    return 10
def numbers():
    yield 10
    yield 20

6. Second Largest Element
Question:

Find the second largest element without using sort() or sorted().

Answer:
numbers = [10, 25, 5, 40, 30]

largest = numbers[0]
second = numbers[0]

for n in numbers:
    if n > largest:
        second = largest
        largest = n
    elif n > second and n != largest:
        second = n

print("Second Largest =", second)

Output:

Second Largest = 30
Important idea:
largest stores the largest number.
second stores the second largest number.
We update them while traversing the list.

Answer:

words = sentence.split()
frequency = {}

for word in words:
    if word in frequency:
        frequency[word] += 1
    else:
        frequency[word] = 1

for word in frequency:
    print(word, ":", frequency[word])

9. Prime Number Using Function
Answer:
def is_prime(n):
    if n < 2:
        return False

    i = 2

    while i * i <= n:
        if n % i == 0:
            return False
        i += 1

    return True


num = int(input("Enter a number: "))

if is_prime(num):
    print("Prime")
else:
    print("Not Prime")
Example:

Input:

17

Output:

Prime
Why don't we check all numbers up to n-1?

We only need to check divisors up to √n.

If a number has a factor greater than √n, it must have another factor smaller than √n.

Therefore, checking:

i * i <= n

is sufficient and makes the program more efficient.

OR – Sum of Even and Odd Numbers
def calculate_sum(numbers):
    even_sum = 0
    odd_sum = 0

    for n in numbers:
        if n % 2 == 0:
            even_sum += n
        else:
            odd_sum += n

    return even_sum, odd_sum


numbers = [10, 15, 20, 25, 30]

even, odd = calculate_sum(numbers)

print("Even Sum =", even)
print("Odd Sum =", odd)

Output:

Even Sum = 60
Odd Sum = 40

OR – BankAccount Class
class BankAccount:
    def __init__(self, account_holder, balance):
        self.account_holder = account_holder
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount
        print("Amount deposited:", amount)
        print("Balance:", self.balance)

    def withdraw(self, amount):
        if amount <= self.balance:
            self.balance -= amount
            print("Amount withdrawn:", amount)
            print("Balance:", self.balance)
        else:
            print("Insufficient Balance")


account = BankAccount("Rahul", 10000)

account.withdraw(12000)

Output:

Insufficient Balance

If:

account.withdraw(2000)

Output:

Amount withdrawn: 2000
Balance: 8000

11. Inheritance
Question:

Create a parent class Vehicle with start() and child class Car with drive().

Answer:
class Vehicle:
    def start(self):
        print("Vehicle started")


class Car(Vehicle):
    def drive(self):
        print("Car is driving")


car = Car()

car.start()
car.drive()

Output:

Vehicle started
Car is driving
Explanation:

Car inherits the start() method from Vehicle.

So the child class can use:

Its own method → drive()
Parent's method → start()
OR – Method Overriding
class Animal:
    def sound(self):
        print("Animal makes a sound")


class Dog(Animal):
    def sound(self):
        print("Dog barks")


dog = Dog()
dog.sound()

Output:

Dog barks
Explanation:

The Dog class provides its own version of the sound() method. This is called method overriding.

OR – Read File and Count Lines, Words and Characters
try:
    file = open("sample.txt", "r")

    lines = 0
    words = 0
    characters = 0

    for line in file:
        lines += 1
        words += len(line.split())
        characters += len(line)

13. Generator – Even Numbers from 1 to N
Answer:
def even_numbers(n):
    for i in range(1, n + 1):
        if i % 2 == 0:
            yield i


n = int(input("Enter N: "))

for num in even_numbers(n):
    print(num)
Input:
10
Output:
2
4
6
8
10
Why is a generator preferred?

A generator produces values one at a time using yield instead of storing the complete list in memory.

Therefore, generators are memory efficient, especially when dealing with large amounts of data.

OR – Decorator
Question:

Write a decorator that prints:

Function Started
Function Finished

before and after executing another function.

Answer:
def my_decorator(func):
    def wrapper():
        print("Function Started")
        func()
        print("Function Finished")

    return wrapper


@my_decorator
def hello():
    print("Hello Python")


hello()
Output:
Function Started
Hello Python
Function Finished
How it works:
@my_decorator

means the hello() function is passed to my_decorator.

The decorator adds extra behavior before and after the original function executes.
